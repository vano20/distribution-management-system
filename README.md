# Distribution Management System

## Feature

This apps still <b>unfinished</b>, the demo only show login mechanism with 2 roles. This is happens due to me cannot complete the whole project in given time even with additional extended time.

## Stack

- Nuxt 3 - Meta framework
- NuxtUI - Tailwind based UI
- Pinia - State management
- Typescript - Type safety

`This is the stack that I am familiar the most, Nuxt 3 are meta framework that support SSR, ISR, SSG based on Vue 3. NuxtUI is comprehensive, and complete UI based on Tailwind. Pinia are Vue's state management recommendation with great support from contributors, Typescript to improve DX and minimze bugs on the code`

## Setup

Install depedencies

```bash
# pnpm
pnpm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# pnpm
pnpm dev
```

## Production

Build the application for production:

```bash
# pnpm
pnpm build
```

Locally preview production build:

```bash
# pnpm
pnpm preview
```
